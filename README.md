# gold-miner-game-java
Gold Miner Game
A Java implementation of the classic Gold Miner game developed using object-oriented programming principles.

Features：

- Java Swing GUI
- Object-oriented design
- Collision detection
- Score tracking
- Pause and resume functionality
- High-score ranking system
- Sound effects
# Concepts Demonstrated
- Abstraction
- Inheritance
- Polymorphism
- Collision Detection
- File I/O
- Bubble Sort
# Technologies
- Java
- Java Swing
- OOP
- File I/O
- Graphics2D
